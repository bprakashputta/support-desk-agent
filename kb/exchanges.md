# Exchanging delivered items

## What can be exchanged
Items from a **delivered** order can be exchanged for a different option of the same product, for example a different size or color of the same t-shirt. You cannot exchange one product type for another, such as a shirt for shoes. The new item must be in stock.

## Exchange only once
An exchange can be requested only once per delivered order. Make sure you list every item you want to exchange before confirming.

## Price differences
If the new item costs more, you pay the difference; if it costs less, you receive the difference. Choose a payment method on your account for this. A gift card must have enough balance to cover any amount owed.

## What happens next
The order status becomes "exchange requested" and you receive an email explaining how to send back the original items. You do not need to place a new order.
