# Returning delivered items

## Eligibility
Items can be returned only from orders in **delivered** status. You can return some or all of the items in an order, but a delivered order can be returned or exchanged only once, so include every item you want to send back in the same request.

## Where the refund goes
Refunds go either to the original payment method of the order or to an existing gift card on your account. We cannot refund to a different credit card or PayPal account.

## What happens next
After the return is confirmed, the order status becomes "return requested" and you receive an email with instructions on how and where to send the items.
